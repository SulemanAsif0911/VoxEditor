# Vox Editor (native Android, Kotlin + Jetpack Compose + Media3)
1. Create a GitHub repo, upload everything in this folder (keep `.github/` folder).
2. Open the **Actions** tab → "Build APK" runs automatically (or press *Run workflow*).
3. When finished, open the run → **Artifacts** → download `VoxEditor-debug-apk` → unzip → install `app-debug.apk`.
